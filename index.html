4.7连接公司系统 · 连接器(MCP)Connecting Company Systems · MCP

MCP（Model Context Protocol）是一个开源标准，允许 Claude、ChatGPT 等 AI 应用连接外部系统或外部数据源。通过 MCP，Claude 可安全接入公司在用的系统——例如 Lark(飞书)套件与数据仓库，实现取数、查文档、整理信息，无需来回复制粘贴。MCP (Model Context Protocol) is an open-source standard that lets AI applications such as Claude and ChatGPT connect to external systems or data sources. Through MCP, Claude can securely connect to the systems the company already uses — such as the Lark suite and the data warehouse — to pull data, search docs, and organize information, with no copy-pasting required.

MCP 连接的两种类型Two types of MCP connection

远程连接器（Remote MCP）公司主用Our setupRemote MCP 公司主用Our setup

通过一个公网 URL 接入，Claude 从云端直接连接，网页 / 桌面 / 手机都能用，无需在本机安装。公司的 ChatBI 连接器属于这一种。Connects via a public URL; Claude reaches it from the cloud, so it works on web / desktop / mobile with nothing to install locally. The company's ChatBI connector is this type.

本地连接器（Local MCP）Local MCP

仅在 Claude Desktop 通过本机配置文件运行，连接本地网络中的系统。Runs only in Claude Desktop via a local config file, connecting to systems on your local network.

以 Lark MCP 为例Example: the Lark MCP

连接 Lark 后，Claude 通过 Lark MCP 服务器调用一组飞书工具，即可直接操作 Wiki、云文档、多维表格、任务、日历、邮件等。整个链路是：Claude（客户端）→ Lark MCP 服务器 → Lark 套件。Once connected, Claude calls a set of Lark tools through the Lark MCP server to work directly with Wiki, Docs, Base, tasks, calendar, mail, and more.
